## 1. Product Overview

### 1.1 Purpose

AsyncAgent WebApp is a SvelteKit 5 web application for managing autonomous AI agents that decompose high-level goals into Directed Acyclic Graphs (DAGs) of executable tasks. The system allows users to:

- Define and manage AI agent configurations (prompt templates)
- Create DAGs from natural language goals
- Execute DAGs and monitor their progress in real-time
- View execution artifacts and results
- Schedule recurring DAG executions via cron

### 1.2 Core Concepts

| Concept | Description |
|---------|-------------|
| **Agent** | An AI configuration with a name, version, and prompt template. Agents decompose goals into tasks. |
| **DAG** | Directed Acyclic Graph - A structured plan of interdependent tasks generated from a user's goal. |
| **DAG Execution** | A single run of a DAG, containing multiple sub-steps (tasks). |
| **Sub-Step** | An individual task within an execution - either a tool call or LLM inference. |
| **Artifact** | Output files generated by DAG executions (typically markdown documents). |

### 2.1 Core Framework
- **SvelteKit 5** with file-based routing

- **Lucide Svelte** - icon library

## Appendix A: Status Color Mapping

### Goal/DAG Statuses
| Status | Color | TailwindCSS Class |
|--------|-------|-------------------|
| active | Green | `bg-green-100 text-green-800` |
| paused | Yellow | `bg-yellow-100 text-yellow-800` |
| ready | Green | `bg-emerald-500` |
| pending | Amber | `bg-amber-500` |
| failed | Red | `bg-red-500` |

### Execution/Run Statuses
| Status | Color | TailwindCSS Class |
|--------|-------|-------------------|
| pending | Gray | `bg-gray-100 text-gray-800` |
| running | Blue | `bg-blue-100 text-blue-800` |
| completed | Green | `bg-green-100 text-green-800` |
| failed | Red | `bg-red-100 text-red-800` |
| suspended | Yellow | `bg-yellow-100 text-yellow-800` |

## Appendix C: Glossary

| Term | Definition |
|------|------------|
| DAG | Directed Acyclic Graph - a task plan with dependencies |
| Sub-Task | An individual task within a DAG blueprint |
| Sub-Step | An executed instance of a sub-task |
| Agent | AI configuration with prompt template |
| Artifact | Output file from DAG execution |
| Decomposition | Process of breaking a goal into tasks |
| SSE | Server-Sent Events - for real-time updates |
