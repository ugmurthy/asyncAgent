## 1. Product Overview

### 1.1 Purpose

AsyncAgent WebApp is a SvelteKit 5 web application for managing autonomous AI agents that decompose high-level goals into Directed Acyclic Graphs (DAGs) of executable tasks. The system allows users to:

- Define and manage AI agent configurations (prompt templates)
- Create DAGs from natural language goals
- Execute DAGs and monitor their progress in real-time
- View execution artifacts and results
- Schedule recurring DAG executions via cron

### 1.2 Core Concepts

| Concept | Description |
|---------|-------------|
| **Agent** | An AI configuration with a name, version, and prompt template. Agents decompose goals into tasks. |
| **DAG** | Directed Acyclic Graph - A structured plan of interdependent tasks generated from a user's goal. |
| **DAG Execution** | A single run of a DAG, containing multiple sub-steps (tasks). |
| **Sub-Step** | An individual task within an execution - either a tool call or LLM inference. |
| **Artifact** | Output files generated by DAG executions (typically markdown documents). |

## 6. API Integration

### 6.1 Client Setup (`$lib/api/client.ts`)

```typescript
import { AsyncAgentClient } from '@async-agent/shared/js-client';

const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || 'http://localhost:3000';

export const client = new AsyncAgentClient({
  BASE: API_BASE_URL + '/api/v1'
});
```

### 6.2 SDK Services Available

The `AsyncAgentClient` provides the following services:

| Service | Description |
|---------|-------------|
| `client.agents` | Agent CRUD operations (`listAgents`, `createAgent`, `getAgent`, `updateAgent`, `deleteAgent`, `activateAgent`, `resolveAgent`) |
| `client.dag` | DAG operations (`createDag`, `executeDag`, `createAndExecuteDag`, `listDags`, `getDag`, `updateDag`, `deleteDag`, `resumeDag`, `runDag`, `listDagExecutions`, `getDagExecution`, `deleteDagExecution`, `getDagExecutionSubSteps`, `getDagExecutions`, `listScheduledDags`, `runDagExperiments`) |
| `client.health` | Health checks (`getHealth`, `getHealthReady`) |
| `client.artifacts` | Artifact operations (`listArtifacts`, `getArtifact`) |
| `client.task` | Task execution (`executeTask`) |
| `client.goals` | Goal operations (`listGoals`, `createGoal`, `getGoal`, `updateGoal`, `deleteGoal`, `triggerGoalRun`, `pauseGoal`, `resumeGoal`) |
| `client.tools` | Tool definitions (`listTools`) |
| `client.runs` | Run operations |

### 6.3 Error Handling Pattern

```typescript
import { ApiError } from '@async-agent/shared/js-client';

try {
  const result = await client.dag.createDag({ requestBody: { ... } });
} catch (error) {
  if (error instanceof ApiError) {
    if (error.status === 409) {
      // Handle conflict
    } else if (error.status === 404) {
      // Handle not found
    }
  }
  notifications.error('Failed to create DAG');
}
```

### 6.4 SSE Streaming (Direct Fetch)

For real-time streaming, use native EventSource (not covered by SDK):

```typescript
const eventSource = new EventSource(
  `${API_BASE_URL}/api/v1/dag-executions/${executionId}/stream`
);

eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  // Handle event
};

eventSource.onerror = () => {
  eventSource.close();
};
```

## Appendix A: Status Color Mapping

### Goal/DAG Statuses
| Status | Color | TailwindCSS Class |
|--------|-------|-------------------|
| active | Green | `bg-green-100 text-green-800` |
| paused | Yellow | `bg-yellow-100 text-yellow-800` |
| ready | Green | `bg-emerald-500` |
| pending | Amber | `bg-amber-500` |
| failed | Red | `bg-red-500` |

### Execution/Run Statuses
| Status | Color | TailwindCSS Class |
|--------|-------|-------------------|
| pending | Gray | `bg-gray-100 text-gray-800` |
| running | Blue | `bg-blue-100 text-blue-800` |
| completed | Green | `bg-green-100 text-green-800` |
| failed | Red | `bg-red-100 text-red-800` |
| suspended | Yellow | `bg-yellow-100 text-yellow-800` |

## Appendix C: Glossary

| Term | Definition |
|------|------------|
| DAG | Directed Acyclic Graph - a task plan with dependencies |
| Sub-Task | An individual task within a DAG blueprint |
| Sub-Step | An executed instance of a sub-task |
| Agent | AI configuration with prompt template |
| Artifact | Output file from DAG execution |
| Decomposition | Process of breaking a goal into tasks |
| SSE | Server-Sent Events - for real-time updates |
